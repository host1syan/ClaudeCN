# ClaudeCN 文档中心

ClaudeCN 是一套**全中文提示词**的仿 Claude 智能体工作台，支持 macOS、Windows、Linux，提供终端 CLI、本地服务端、桌面客户端和 Docker 部署四种使用方式。

面向中文开发工作流，内置 Claude CN 与 Kilo Free 免费渠道，支持长任务缓存、多会话、多 Agent、记忆、Skills、Computer Use、H5 远程访问和 IM 接入。
