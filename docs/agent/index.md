# 多 Agent 系统文档

Claude Code 的多 Agent 系统是一套**智能任务编排框架**，让主代理生成多个专业化的子代理（Subagent），各自独立并行执行不同任务，最终汇总结果，把大任务拆分为多个专业小任务，提高效率。

## 文档目录

### [01-usage-guide.md](./01-usage-guide.md) — 使用指南

面向用户的完整使用手册，涵盖：

- **六种内置 Agent**：通用、探索等专业代理及其工具池
- **如何生成 Agent**：在对话中按需派生子代理
- **后台任务管理**：并行任务运行与进度查看
- **Agent Teams 协作**：多代理分工合作
- **自定义 Agent 与权限**

**适合人群**：所有用户

---

## 开始使用

1. 阅读[使用指南](./01-usage-guide.md)了解六种内置 Agent 和适用场景。
2. 在复杂任务中让 Claude 自动编排子代理，或将大任务拆解后并行执行。
3. 用后台任务管理同时推进多项工作，用 Agent Teams 协作完成大型任务。
