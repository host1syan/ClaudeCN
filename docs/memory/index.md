# 记忆系统文档

Claude Code 的记忆系统是一套**基于文件的持久化知识库**，让 Claude 跨多次对话保持对用户有项目的理解，记住该长期保留的偏好与信息。

## 文档目录

### [01-usage-guide.md](./01-usage-guide.md) — 使用指南

面向用户的完整使用手册，涵盖：

- **四种记忆类型**：User（用户画像）、Feedback（行为反馈）、Project（项目动态）、Reference（外部资源）
- **记忆方式**：自动提取、显式请求、命令触发
- **管理操作**：遗忘、忽视、手动编辑
- **如何活用**：何时何地记忆，避免冗余

**适合人群**：所有用户

---

## 开始使用

1. 阅读[使用指南](./01-usage-guide.md)了解记忆的类型和触发方式。
2. 正常对话即可，Claude 会按需记录值得长期保留的信息。
3. 需要手动记忆或遗忘时，使用对应命令。

记忆只记录无法从代码或 Git 历史中推导出的信息（如用户职责、偏好、项目背景），不重复代码本身可得的内容。
